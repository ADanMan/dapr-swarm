# Рой / Dapr Swarm

Локальное рабочее пространство для задач, которые выполняет иерархический рой GLM-агентов. Координатор обязательно делегирует работу; специалисты могут создавать своих агентов. Веб-интерфейс показывает дерево работы, файлы, бюджеты, проверки результата и автоматические продолжения после временных сбоев.

Это самостоятельное приложение на Dapr Agents. Оно не является официальным продуктом Dapr, Swarms, BeeGate или OpenAI. Репозиторий не содержит код сервиса BeeGate: нужен собственный доступ к совместимому API и выбранной модели.

## Возможности

- Русскоязычная GUI на `http://127.0.0.1:8788`, постановка задач с вложениями, просмотр и скачивание результатов.
- Dapr workflow, состояние в Redis, история задач и очередь команд в SQLite.
- Роли координатора, руководителя группы, исследователя, аналитика, исполнителя и проверяющего; связи родителей и детей сохраняются.
- По умолчанию до 2000 дочерних агентов и 20000 вызовов модели за задачу. Окно работы — 16 специалистов; одновременно допускается до 8 HTTP-запросов к модели. Эти пределы не доказывают возможность запуска 2000 агентов одновременно.
- Поиск через отдельный SearXNG. Код пишет GLM, локальные команды выполняет sandbox установленного Codex CLI без запроса к GPT.
- Финальный reviewer регистрирует реальную проверку через `run_validation`. GUI показывает критерии, команду, exit code и SHA-256 файлов. Изменение результата делает приёмку устаревшей.
- До трёх автоматических продолжений после подтверждённых временных сбоев, с паузами 15/60/180 секунд. Сохраняются файлы и остатки бюджета. Stop отменяет восстановление.
- CLI и устанавливаемый skill для Hermes, привязанный к Git-тегу.

## Первый запуск на Mac

Нужны Python 3.12, `uv`, Docker Desktop и Codex CLI с поддержкой используемого sandbox-профиля. Worker использует macOS и Unix API. Linux и другие версии Codex CLI требуют отдельной проверки. Ключ и доступ к GLM не предоставляются.

```sh
git clone https://github.com/ADanMan/dapr-swarm.git
cd dapr-swarm
uv sync --frozen
cp .env.example .env
chmod 600 .env
```

Отредактируйте `.env`: укажите `BEEGATE_BASE_URL` с путём API, точный `BEEGATE_MODEL` своего провайдера и `BEEGATE_API_KEY`. Имена переменных сохранены для совместимости. Адрес и модель из примера — заглушки; launcher откажется запускать их. Переменные процесса имеют приоритет над `.env`. Конфигурация и ключи других приложений автоматически не читаются.

```sh
uv run python scripts/start.py --no-open
./swarm health
```

Откройте `http://127.0.0.1:8788`. Для запуска двойным кликом после установки зависимостей доступен `start.command`. Для остановки без удаления истории используйте `stop.command`. Не запускайте одновременно другую копию приложения на том же порту или с тем же Compose project name.

Launcher генерирует случайный `SEARXNG_SECRET` в памяти. Для постоянного значения можно задать собственный секрет в `.env`. [Документация настройки SearXNG](https://docs.searxng.org/admin/settings/settings_server).

## CLI

```sh
./swarm --json submit --prompt-file examples/task.md --file examples/input.json --agents 8 --calls 80 --commands 20 --command-reserve 5 --work-window 2
./swarm show TASK_ID
./swarm wait TASK_ID --deadline 600
./swarm files TASK_ID
./swarm download TASK_ID outputs/result.json --output ./result.json
./swarm stop TASK_ID
./swarm resume TASK_ID
```

`wait` следует за автоматическими продолжениями в пределах общего deadline. Код 0 означает завершение workflow; отдельно смотрите `acceptance.status` и итоговые файлы. Код 1 означает ошибку/остановку, 3 — истечение deadline. Ctrl-C прекращает только ожидание.

Ручной `resume` создаёт связанный запуск с прежними полными лимитами. Автоматическое продолжение использует только оставшиеся ресурсы. Не запускайте ручное возобновление во время запланированного автоматического восстановления. Настоящий отказ ключа, исчерпанный бюджет и ошибка локальной команды не повторяются бесконечно.

## Hermes

```sh
python3 scripts/install_hermes_skill.py --tag v0.4.1
```

Установщик извлекает skill и самостоятельный Python-клиент из тега, сохраняет commit и SHA-256 в `RELEASE.json`. Существующую установку он не перезаписывает. Перед обновлением сохраните старую папку вне `~/.hermes/skills/`. Инструкции: [skills/swarm/SKILL.md](skills/swarm/SKILL.md).

## Данные и ограничения

`data/` содержит историю, входные материалы, результаты и журналы. Этот каталог, `.env`, ключи и окружения исключены из Git и Docker build context. Не публикуйте их самостоятельно. GUI предназначена для одного доверенного пользователя на loopback; аутентификация для удалённого доступа не реализована. Не выставляйте порт через туннель или публичный reverse proxy.

Запросы и относящийся к задаче контекст отправляются выбранному провайдеру модели. Поисковые запросы идут через SearXNG к поисковым системам. Передавайте только материалы, которые разрешено обрабатывать такими сервисами. Контейнер приложения получает API-ключ; пользователи с доступом к Docker могут читать его environment.

Приёмка подтверждает выполнение зарегистрированной команды и неизменность охваченных файлов. Она не доказывает смысловую полноту произвольного проверяющего скрипта. Проверка обязана возвращать ненулевой код при нарушении критериев. Восстановление создаёт новую попытку той же цели, а не возобновляет внешнюю операцию посередине.

## Разработка и проверки

```sh
uv run pytest -q
npm ci --ignore-scripts
npm run test:ui
```

Обычные тесты работают с локальными фикстурами. Живые проверки провайдера и массовые прогоны выполняйте отдельно, с явным бюджетом. Для первой публичной версии выполнены только лёгкие офлайн-проверки, описанные в [PUBLICATION.md](PUBLICATION.md). Старые локальные протоколы и результаты задач не публикуются и не считаются проверкой этой сборки.
